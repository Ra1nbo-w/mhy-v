# 漫画源维护记录：2.3.1

检查了八个源的网页解析、请求入口、分类路径、分页与图片处理。本次修改四个源；没有依据的接口和站点限制保持原状。

## 已修复

- 包子与 MYCOMIC：为 13 处原有网页解析对象补上 `try/finally` 释放。正常返回、解析抛错均释放，包含原实现中仍被复用的发现页、搜索、排行和章节加载函数。
- MYCOMIC：统一拒绝非 200 响应，避免部分新入口把 404/500 页面解析成空内容。保留发现页单个栏目失败时返回其他已加载栏目的行为。
- 漫蛙：修复 `/booklist?tag=...` 被编码为题材文本的问题。保留网站链接中的已知筛选参数，重新使用用户请求的页码，不携带链接中旧的 `page`。
- Komiic：成功登录或退出时清理图片票据；退出前正在请求的票据和章节图片响应不会重新填充缓存，也不会删除新账号正在进行的同名请求。
- 包子：为省略协议的图片地址补齐 HTTPS；没有取得图片时返回明确错误，不再返回成功的空章节。

## 验证

- `tools/validate.cjs`：八个源语法及三个索引的元数据。
- `tools/test-ui.cjs`：发现页、分类、组合筛选及分页约定。
- `tools/test-baozi-verification.cjs`：首次安装、升级及登录回调约定。
- `tools/test-source-lifecycle.cjs`：正常/异常路径释放、HTTP 错误、图片地址、分类链接和账号切换并发场景。

这些是离线模拟回归，不代替 Android/Windows 实机阅读、网站登录或下载验证。MYCOMIC 首页按位置区分精选与推荐的逻辑仍需可访问网页进一步核对；此次未将它宣称为已确认修复。包子网站验证和其他站点的网络、阅读额度限制也仍存在。
