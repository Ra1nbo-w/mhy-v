# 包子漫画登录与验证（2.2.2）

2.2.1 使用公开分类页完成“登录”，可能在网站账号认证前就返回应用。2.2.2 改为从账号书架进入网页登录，只在书架地址和标题匹配后同步会话，并用应用网络请求再次检查书架上的账号操作控件。分类页能访问只表示站点验证通过，不再作为网站账号登录的依据。

## 使用方法

1. 在漫画源管理更新包子漫画到 2.2.2，完全退出再启动应用；最低应用版本为 1.18.0。
2. 打开本源“登录 → 网页登录”，自行完成站点验证和账号登录。
3. 若登录后停在主页，点击网站的“我的书架”。普通主页不触发账号登录完成，防止误保存访客状态。
4. 应用保存会话后，会请求书架检查实际账号状态。通过才显示“网站账号已同步”；请求失败或仍为访客会报错，并清除错误的账号登录标记。
5. 返回后可点击“检查登录同步”。“检查验证”仍只检查分类页；请分别测试搜索、详情和章节图片。

验证、登录和应用请求使用相同网络设置；代理是否是必要条件仍需在设备上实测。本次修改没有证明网站直连一定可用。外部浏览器登录不会自动同步到应用。

## 应用端补丁

`patches/venera-next-webview-session.patch` 基于 VeneraNext v1.18.0 对应源码，包含：

- 保存实际 WebView User-Agent，避免 Android 使用固定 Windows 标识。
- 补上页面加载完成检查，读取当前实际网址、标题和加载状态；导航开始时不再把旧标题与目标网址拼成成功状态。
- 保留可取得的 Cookie 路径、有效期、Secure 和 HttpOnly 属性，避免根路径 Cookie 保存到书架路径后失效。旧 Android WebView 可能不提供全部属性，此时无法凭空恢复缺失值。
- 账号成功回调通过后才保存已登录标记；回调失败可以重试，不再缓存一个永远失败的回调结果。

这个补丁需要应用到 VeneraNext 源码并重新构建 Android/Windows 安装包；更新漫画源不会安装应用补丁。仓库尚未提供修补后的安装包。
