## 尚未按预览实现的部分

- **MYCOMIC 日排行**：先前设计包含日排行，但公开参考脚本只有周、月、历史，当前网站排行榜被403拦截，无法确认真实日榜参数。保留已知月榜，不猜测 `day` 参数，也不拿周榜冒充日榜。取得正常排行榜页面后可继续补齐。
- **包子和 MYCOMIC 验证后的实际显示**：本环境仍被网站拦截。分类请求组合已做模拟检查，首页数据及更多入口没有宣称联网通过。未使用固定 Cookie，验证问题不因本次 UI 修订而消失。
- **卡片样式、列数、标签位置**：由 VeneraNext 控制。源文件可设置分区、分类和筛选，无法单独实现预览里的任意样式、轮播或角标。分类页是否展示还取决于应用启用的分类源设置。
- **拷贝排行榜分页和封面**：读取官网首页日/周/月/总分栏，每榜男、女频合计最多20条，去重后可能减少；该区域无下一页，明确只返回一页。首页没有提供的封面保持空值，不编造图片。

## 检查证据和范围

- 八源脚本语法、三个索引、版本/更新链接一致性通过。
- 使用保存的真实网页验证六个可解析源的发现分区、搜索、详情和章节；漫画屋六个栏目各6本，拷贝四榜各20条。
- 实际请求：漫自由完结精选、拷贝推荐和全新上架返回200；新增 Komiic 完结查询返回200。MYCOMIC 排行榜返回403，停止读取。
- 模拟检查包子和 MYCOMIC 组合筛选，确认既保留题材，也发送地区、状态等参数；数字首字母分组不会被应用的连字符分隔规则截断。
- `node tools/validate.cjs` 和 `node tools/test-ui.cjs` 可重复执行，不需要账号或 Cookie。它们不是 Android 真机、完整阅读和离线下载测试。

更新方法：在应用中更新对应源，再刷新发现页；仍为旧结构时完全退出应用后重新启动。无需删除收藏或历史。
