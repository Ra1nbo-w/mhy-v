## 尚未按预览实现的部分

- **MYCOMIC 首页真实分区**：可访问的网页文本显示推荐给你等栏目，但本环境直接请求首页仍返回403。推荐列表的位置按网页顺序和模拟页面检查；需在可访问的设备上核对真实卡片内容。
- **包子和 MYCOMIC 验证后的实际显示**：本环境仍被网站拦截。分类请求组合已做模拟检查，首页数据及更多入口没有宣称联网通过。未使用固定 Cookie，验证问题不因本次 UI 修订而消失。
- **卡片样式、列数、标签位置**：由 VeneraNext 控制。源文件可设置分区、分类和筛选，无法单独实现预览里的任意样式、轮播或角标。分类页是否展示还取决于应用启用的分类源设置。
- **拷贝排行榜分页和封面**：读取官网首页日/周/月/总分栏，每榜男、女频合计最多20条，去重后可能减少；该区域无下一页，明确只返回一页。首页没有提供的封面保持空值，不编造图片。

- 八源脚本语法、三个索引、版本/更新链接一致性通过；八源分类页均无「常用」。
